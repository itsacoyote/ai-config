# Git Commits

Write commits as a human engineer would. Clean, direct, professional.

Before committing, run the project's own mechanical checks (typecheck, lint, format,
tests — whatever the project defines) and fix what they surface, so the commit doesn't
turn CI red on push.

## Format

Use [Conventional Commits](https://www.conventionalcommits.org/):

```
<type>(<scope>): <short description>

[optional body]
```

**Types** — this is the canonical conventional-commit type list (the `branch-names` and
`create-pr` skills defer here):

| Type | Use for |
|---|---|
| `feat` | A new feature |
| `fix` | A bug fix |
| `refactor` | A code change that neither fixes a bug nor adds a feature |
| `perf` | A change that improves performance |
| `docs` | Documentation only |
| `test` | Adding or updating tests |
| `style` | Formatting/whitespace only, no behavior change |
| `chore` | Tooling, dependencies, config, or other maintenance |
| `ci` | CI/CD configuration changes |

**Rules:**

- Lowercase, no trailing period
- Description in imperative mood ("add X", not "adds X" or "added X")
- Scope is optional; use it when the change is isolated to a clear area
- Body is optional; use it only when the why isn't obvious from the title

## No AI Attribution — Ever

Do not include any of the following:

- `Co-Authored-By:` trailers of any kind
- `Generated by`, `Written by AI`, robot emoji, or any similar attribution
- Any mention of the AI tool or model that produced the change

The commit must read as if the engineer who built the change wrote it themselves. If the
harness injects an attribution trailer by default, remove it before the commit lands.

## Examples

```
feat(agents): add model assignments to all agent frontmatter
fix(auth): handle expired token on refresh
docs: update setup instructions for new env vars
chore: add .gitignore for macOS and editor artifacts
```

## Show the message after committing

After running `git commit`, surface the **exact committed message** back to the user —
don't just say "committed" or "it follows the rules." Print the full subject and body
verbatim so they can verify it without digging into git themselves:

```
git show -s --format=%B HEAD
```

Include that output (subject + any body) in your reply. If you amended or rewrote a
message, show the updated one.

## Common Mistakes

| Mistake | Fix |
|---|---|
| `Co-Authored-By: ...` | Remove the trailer entirely |
| `feat: adds X` | `feat: add X` (imperative) |
| `feat: Add X` | `feat: add X` (lowercase) |
| Vague body explaining what the code does | Omit it, or explain *why* only |
